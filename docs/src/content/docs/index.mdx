Rovie Route is a gateway. You send it the request body you would have sent OpenAI, it
routes to whichever provider actually serves the model you named, and it draws
the cost down from a balance you topped up in naira, shillings or cedis.

The integration is a base URL and a key.

<Code
  lang="diff"
  title="Any OpenAI client, unchanged"
  code={`  from openai import OpenAI

  client = OpenAI(
-     base_url="https://api.openai.com/v1",
-     api_key=os.environ["OPENAI_API_KEY"],
+     base_url="https://api.rovie.africa/v1",
+     api_key=os.environ["ROVIE_API_KEY"],
  )

  response = client.chat.completions.create(
-     model="gpt-4o",
+     model="anthropic/claude-sonnet-5",
      messages=[{"role": "user", "content": "Hello"}],
  )`}
/>
