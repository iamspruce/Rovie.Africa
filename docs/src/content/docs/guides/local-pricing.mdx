Every price Rovie Route shows is converted from USD into the currency of the country
on your account. This page is how to do the same conversion yourself — for a
cost estimator, an internal dashboard, or a price shown to your own users.

Two unauthenticated endpoints, and some arithmetic that is easy to get wrong.

## The endpoints

[`GET /models`](/api/operations/listcatalog/) gives every model and its rates:

```json
{
  "models": [
    {
      "litellmModelName": "anthropic/claude-sonnet-5",
      "provider": "anthropic",
      "name": "Claude Sonnet 5",
      "limit": { "context": 200000, "output": 64000 },
      "cost": { "input": 3, "output": 15, "cache_read": 0.3 }
    }
  ]
}
```

[`GET /fx/rates`](/api/operations/getfxrates/) gives the conversion:

```json
{
  "currencies": { "NGN": { "ratePerUsd": 1512.4 }, "KES": { "ratePerUsd": 129.2 } },
  "supported": ["NGN", "KES", "GHS", "UGX", "..."],
  "fetchedAt": 1786579200000
}
```

Neither needs a key. Both back the public pages on rovie.africa, so quoting
through them gives your reader the same number the site shows them.

## The one thing to get right

<Aside type="danger" title="Per million, not per token">
`cost.input` and `cost.output` are **USD per one million tokens**.

`{"input": 3}` means **$3.00 per million tokens**, not $3 per token. Reading it
the second way puts a price out by a factor of a million — which is a mistake
this codebase has already made once, and it is not subtle when it reaches a
user.
</Aside>

## The arithmetic

```python
def local_cost(model, prompt_tokens, completion_tokens, rate_per_usd):
    """What one call costs, in the local currency's major unit."""
    usd = (
        prompt_tokens * model["cost"]["input"] / 1_000_000
        + completion_tokens * model["cost"]["output"] / 1_000_000
    )
    return usd * rate_per_usd
```

Worked through, for Claude Sonnet 5 at ₦1,512.4 to the dollar, on a call with a
2,000-token prompt and a 500-token answer:

```text
input   2,000 × $3.00  / 1,000,000 = $0.006
output    500 × $15.00 / 1,000,000 = $0.0075
                                     ───────
                             total   $0.0135  ≈  ₦20.42
```

## Handling the gaps honestly

Three cases where the naive version prints something wrong.

**A model with no published price.** `cost` is optional — models.dev does not
have a rate for everything, and Rovie Route passes through rather than inventing one.
Show "price unavailable"; do not treat a missing rate as zero.

**A currency with no rate.** If a code is absent from `currencies`, the rate
feed did not carry it. Fall back to showing USD, labelled as USD. A naira
symbol in front of a dollar figure is worse than no conversion at all.

**A stale rate.** `fetchedAt` is Unix **milliseconds**, and it is when Rovie Route
last refreshed the feed — not when you asked. Cache accordingly, and if you are
quoting something a user will act on, say when the rate was taken.

```ts
const rate = rates.currencies[currency]?.ratePerUsd;

// No rate is a real case, not an error case.
const display = rate
  ? formatLocal(usd * rate, currency)
  : formatUsd(usd);
```

## Quoting versus paying

Two different lists, and conflating them produces a checkout that fails:

- **Quoting** — every currency in `supported`. Rovie Route can price a model in any
  of them, and the models page does.
- **Paying** — **NGN, UGX, GHS, KES** only. Settling a payment means holding
  funds in that currency, which is a compliance question rather than a
  technical one.

So a visitor in Rwanda sees prices in Rwandan francs and tops up in one of the
four. See [Balance and top-ups](/guides/billing/).

## Rates move

The figure you quote is indicative until money changes hands. Rovie Route locks a
rate when a charge is created — that is the binding one, and it is why a quote
shown before payment is explicitly marked indicative.

If you are showing prices to your own users, either refresh the rate on the
page or timestamp it. A cost estimate carrying last week's naira rate is a
support ticket.

## A complete estimator

```python
import requests

BASE = "https://api.rovie.africa"

def estimate(model_id, currency, prompt_tokens, completion_tokens, calls_per_month):
    models = requests.get(f"{BASE}/models", timeout=10).json()["models"]
    rates = requests.get(f"{BASE}/fx/rates", timeout=10).json()

    model = next(m for m in models if m["litellmModelName"] == model_id)
    if "cost" not in model:
        raise ValueError(f"{model_id} has no published price")

    per_call_usd = (
        prompt_tokens * model["cost"]["input"] / 1_000_000
        + completion_tokens * model["cost"]["output"] / 1_000_000
    )
    monthly_usd = per_call_usd * calls_per_month

    rate = rates["currencies"].get(currency, {}).get("ratePerUsd")
    return {
        "model": model["name"],
        "monthly_usd": round(monthly_usd, 2),
        "monthly_local": round(monthly_usd * rate, 2) if rate else None,
        "currency": currency if rate else "USD",
    }
```

For what a call *actually* cost rather than what it should have, read `usage`
off the response or the [usage dashboard](/guides/usage/) — that is measured,
and this is an estimate.
